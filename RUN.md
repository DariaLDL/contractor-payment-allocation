# Запуск

Python 3.10+, внешние зависимости не нужны.

```sh
python report.py --date 2026-11-10
python -m unittest -v
```

Результат: `output/works.csv` и `output/contracts.csv`. Можно задать `--data` и `--output`.
Исходное задание сохранено в README.md. Экспорт Claude Code отсутствует: решение подготовлено в ChatGPT, не в Claude Code. Для соблюдения требования работодателя необходима отдельная реальная сессия Claude Code с экспортом /export.
