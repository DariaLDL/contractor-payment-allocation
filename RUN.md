# Запуск

Нужен Python 3.10+, внешние зависимости не нужны. (Последняя проверка на Python 3.12.14; на 3.10 и 3.11 не запускалось.)

## Отчёт

```sh
python report.py --date 2026-11-10
```

Результат - два файла (разделитель `;`, UTF-8 с BOM, открываются в Excel):

- `output/works.csv` - по каждой работе: цена, к оплате с учётом отмен, выплачено, осталось, переплата;
- `output/contracts.csv` - по каждому договору: суммы, выплачено, распределено, осталось, переплата, нераспределено.

Параметры:

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `--date YYYY-MM-DD` | обязателен | дата, на которую строится отчёт |
| `--data ПАПКА` | `data/` рядом со скриптом | где лежат `contracts.csv`, `works.csv`, `payments.csv` |
| `--output ПАПКА` | `output/` в текущей папке | куда писать результат |

Эталон на 10.11.2026 лежит в `examples/2026-11-10/`; свежий отчёт на ту же дату должен совпасть с ним байт в байт:

```sh
python report.py --date 2026-11-10 --output /tmp/check
cmp /tmp/check/works.csv examples/2026-11-10/works.csv && cmp /tmp/check/contracts.csv examples/2026-11-10/contracts.csv
```

## Тесты

```sh
python -m unittest -v
```

Ожидаемо: `Ran 31 tests ... OK`. Фактический прогон - в [TEST_RESULTS.md](TEST_RESULTS.md).

## Если запуск не удался

Программа завершится с сообщением о конкретной проблеме в данных (см. раздел «Что делает программа с некорректными данными» в README.md) -
исправьте строку в `data/*.csv`.
