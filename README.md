# Отчёт по оплате работ подрядчиков

Скрипт на Python (только стандартная библиотека), который по договорам, работам и платежам
строит для бухгалтера отчёт **на выбранную дату**: по каждой работе - цена, выплачено, осталось
оплатить; по каждому договору - итоги.

Это решение тестового задания (Candidate B). Исходный текст задания: [TASK.md](TASK.md).

## Быстрый старт

```sh
python report.py --date 2026-11-10
python -m unittest -v
```

Подробнее - [RUN.md](RUN.md).

## Как считается

1. На дату `D` берутся договоры, подписанные не позже `D`.
2. Статус работы определяется по датам: отменена, если `cancelled_at <= D`; принята, если `completed_at <= D`; иначе плановая. Цена отменённой работы к оплате = 0.
3. Платёж учитывается, если `paid_at <= D` и нет возврата `refunded_at <= D`. Платежи в очереди (без `paid_at`) не учитываются.
4. Платёж с `work_id` засчитывается этой работе. Платежи без `work_id` («общий пул») распределяются по порядку: сначала принятые работы по дате приёмки, затем остальные по номеру; каждой - не больше её остатка.
5. Остаток работы не бывает отрицательным: излишек прямого платежа - «Переплата», излишек общего пула - «Нераспределено».
6. Деньги - целые копейки, `float` не используется. Для каждого договора проверяется: `выплачено = распределено по работам + нераспределено`.

## Что делает программа с некорректными данными

Останавливается с понятной ошибкой (а не молча пропускает строку): дубли идентификаторов, неизвестный договор,
платёж привязан к работе чужого договора, сумма не в формате `123.45`, неверная дата, договор без даты подписания,
статус не согласован с датами (например, `done` без `completed_at`, `refunded` без `refunded_at`, возврат раньше оплаты).
